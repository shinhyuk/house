# 🏠 House

관심 있는 집/부동산 매물을 한곳에서 비교하고 관리하기 위한 개인 프로젝트입니다.

## 목표

- 보고 있는 매물 목록을 한눈에 확인
- 가격, 면적, 위치 등 주요 조건 비교
- 원본 매물 링크와 메모 관리
- 관심도와 진행 상태 관리

## 매물 관리 항목

| 항목 | 설명 |
| --- | --- |
| 이름 | 매물을 구분하기 위한 이름 |
| 지역/주소 | 매물 위치 |
| 거래 유형 | 매매 / 전세 / 월세 |
| 가격 | 매매가 또는 보증금/월세 |
| 면적 | 전용/공급 면적 |
| 층 | 해당 층 |
| 원본 링크 | 부동산 매물 페이지 |
| 관심도 | 높음 / 보통 / 낮음 |
| 상태 | 검토중 / 방문예정 / 방문완료 / 보류 / 제외 |
| 메모 | 장단점 및 확인할 내용 |

## 예정 기능

- 매물 추가/수정/삭제
- 목록 및 상세 화면
- 조건별 필터와 정렬
- 관심 매물 표시
- 모바일에서도 보기 편한 UI
